# project-ui-review

用于前端交付前验收的 Agent Skill。指导 AI 按当前项目的需求与设计规范，查看实际界面、完成受影响操作，并在已有授权内修复偏差和复验。

适合页面、样式、组件和交互改动后的检查，也可以只读审查。字体、间距、配色和组件选择沿用项目标准；验收范围限定在本次改动及其直接影响。

## 安装

使用 [skills CLI](https://github.com/vercel-labs/skills)，需要 Node.js 和 npm：

```sh
npx skills add AKin-lvyifang/project-ui-review
```

按提示选择安装到 Codex。也可以下载或克隆本仓库，将以下文件放入 Codex 的技能目录：

```text
~/.codex/skills/project-ui-review/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── evals/
    └── evals.json
```

如果该目录已有内容，先比较并合并需要的文件。安装后，让使用环境重新加载技能，再通过 `$project-ui-review` 调用。

## 使用前准备

提供项目已确认的需求、设计规范或设计参考，可以在 `AGENTS.md` 中注明入口。本 Skill 可独立使用，不依赖 `codex-memory`。规范缺失时，可以检查裁字、遮挡、无法点击等明确问题；涉及设计方向的选择需要补充依据。

实际验收还需要可运行的项目，以及 Agent 获准使用的浏览器或宿主应用工具。本仓库提供行为指导，不自带浏览器、应用运行器或测试环境。没有可运行环境、无法确认运行版本或工具受阻时，相关视觉和交互项应标为**未验证**。

## 验收流程

1. **确定依据**：对应用户任务、受影响页面与状态、需求或规范条目，以及实际组件。
2. **查看运行界面**：先看整页，再看局部；按改动选择尺寸和状态，并核对受影响操作的实际结果。
3. **定位并修复**：说明问题出现的条件和违反的要求，优先修直接原因。只读审查时仅报告问题。
4. **复验并交付**：回到原页面、尺寸和操作状态验证，复用仍有效的证据，说明已检查内容与未验项。

纯样式修改只补相关视觉检查；涉及保存、筛选或批量操作时，再核对对应结果和作用范围。构建成功、截图或成功提示各自只能证明一部分，不能替代尚未执行的检查。

## 调用示例

```text
$project-ui-review 按项目规范验收刚修改的设置弹窗，修复本次改动造成的偏差并复验。
```

```text
$project-ui-review 只读审查这个列表的筛选、分页和批量操作，列出具体问题与最小复验范围，不修改代码。
```

```text
$project-ui-review 检查共享菜单在滚动表格和弹窗中的表现，复用已有普通页面的验证证据。
```

## 维护与许可

具体规则见 [SKILL.md](SKILL.md)。[evals/evals.json](evals/evals.json) 包含 5 个合成情境，仅在维护本 Skill 时按需检查判断与范围控制，日常项目验收无需加载。这些情境不代表真实产品的验收证据。
